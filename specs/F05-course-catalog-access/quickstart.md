# Quickstart Validation — F05

1. As visitor, search/filter catalog and verify only PUBLISHED Free summaries appear; null HSK appears
   in All but not HSK 1–6 filters.
2. Directly request draft, unpublished, archived, invalid-media or Premium content and verify no
   detail/transcript/provider URL/practice is disclosed.
3. Verify visitor detail offers sign-in but cannot enter playback/Player/practice; signed-in learner
   may continue only through F06 access.
4. Withdraw lesson/segment/media after catalog load. Next access must be unavailable/recoverable and
   existing learner progress remains unchanged.
5. Run pagination/filter/order integration tests and frontend empty/loading/unavailable/sign-in UX
   tests with keyboard and responsive states.
